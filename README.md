# myGitHubActions
A test repo to be learning my GitHub Action skills as well as further developing them. Will be using repo to practice creating yml workflows.


# Additions to YML
- Secret Detector for Esri specific secrets such as GIS Enterprise Portal, ArcGIS Online, API keys, and OAuth.
- Linter using Ruff to check for syntax errors, unused variables, and other non-executable checks for the program since arcpy cannot be installed on runner without self-hosted runner.
